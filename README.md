# Татьяна Сыстерова — портфолио QA

Ручное тестирование веб-приложений, мобильных приложений и API. Здесь собраны учебные проекты и примеры моей работы: анализ требований, проектирование проверок, выполнение тестирования и описание дефектов.

## Проекты

### Яндекс Самокат — дипломный учебный проект

**Что проверяла:** веб-форму заказа и экран статуса, мобильное приложение Android, API для работы с курьерами и заказами.

**Моя работа:**

- Разобрала требования и обозначила неясные места; составила карту логики приложения в draw.io.
- Подготовила чек-листы и проверки полей формы заказа с классами эквивалентности и граничными значениями.
- Провела кроссбраузерные проверки веб-приложения по требованиям и макетам Figma.
- Составила тест-кейсы мобильного приложения, в том числе для push-уведомлений и отсутствия сети; использовала эмулятор Android Studio.
- Проверила API через Postman: создание и удаление курьера, получение заказа по номеру. Сверяла результаты запросов с данными в БД.
- Описала обнаруженные дефекты и противоречия в требованиях в YouTrack.

**Пример из выполненных проверок:** для поля «Фамилия» проверяла значения по обе стороны ограничения в 15 символов. При вводе значения длиннее 15 символов ожидаемое ограничение не сработало; результат был отмечен как `FAILED` и оформлен как дефект. Для поля «Дата доставки» проверяла границу между сегодняшним и завтрашним днём; возможность выбрать сегодняшнюю или более раннюю дату также была зафиксирована как дефект.

**Материалы проекта:** [кейс по веб-форме](yandex-scooter-web-case.md) · [чек-лист проверок](yandex-scooter-web-checklist.md) · [пример баг-репорта](yandex-scooter-surname-bug-report.md).

> Учебный проект. Примеры взяты из моих материалов по диплому; исходные документы пока готовятся к публикации в удобном виде без персональных данных и закрытых ссылок.

### Автоматизация тестирования — дипломный учебный проект

Три части диплома по автоматизации хранятся в моём прежнем GitHub-профиле `SysterovaT`:

- [Часть 1: модульные тесты](https://github.com/SysterovaT/Diplom_1) — проверки логики конструктора бургеров, булочек и ингредиентов.
- [Часть 2: тесты API](https://github.com/SysterovaT/Diplom_2) — сценарии создания и входа пользователя, изменения его данных и работы с заказами.
- [Часть 3: тесты веб-интерфейса](https://github.com/SysterovaT/Diplom_3) — регистрация, вход, выход и переключение вкладок с ингредиентами; использован Page Object.

Диплом принят. В отзыве ревьюер рекомендовал вынести тестовые данные из классов тестов во второй и третьей частях и упростить выбор браузера через фабрику драйверов в третьей части. Это следующие задачи по улучшению кода.

### Проверка отчётности — следующий кейс

Планирую оформить отдельный кейс по проверке отчётов и данных: правила расчёта показателей, тестовые наборы, SQL-запросы для сверки и примеры найденных расхождений. Описание и результаты появятся после выполнения работы.

## Инструменты и подходы

`Java` · `Maven` · `JUnit` · `Selenium` · `REST Assured` · `YouTrack` · `Postman` · `Android Studio` · `Figma` · `draw.io` · `DevTools` · `SQL (изучаю и применяю в задачах)`

Основной акцент в тестировании — разобраться, что именно должно происходить, проверить граничные и неоднозначные случаи и оставить понятный след от требования до результата проверки.
