# Яндекс Самокат: проверка мобильного приложения без интернета

## Контекст

Учебный дипломный проект по ручному тестированию мобильного приложения для курьера. В дипломе я подготовила и выполнила тест-кейсы для push-уведомлений и работы приложения без подключения к сети. В исходных тест-кейсах указаны Android 13, эмулятор Android Studio и телефоны Honor 50 Lite и Xiaomi (модель в таблице записана как «Readme 10»).

Результаты ниже относятся к учебному тестированию 2024 года; повторная проверка текущей версии приложения не проводилась.

## Как проверяла отсутствие сети

После входа в приложение включала авиарежим и проверяла действия на разных экранах: кнопки «Принять», «Все», «Мои», фильтр метро, карточку заказа и выход. Для каждого действия сопоставляла появление сообщения об отсутствии сети с требованиями. Затем проверяла, можно ли закрыть сообщение тапом вне его области.

| Тест-кейс | Ожидаемое поведение | Отметка в дипломе |
| --- | --- | --- |
| `in1`: текст сообщения | При отсутствии сети показано сообщение «Отсутствует интернет-соединение» | `FAILED`; текст не соответствовал требованиям, дефект `TATYANA-36` |
| `in2`: закрытие сообщения | Сообщение закрывается только кнопкой «Ок» | `FAILED`; закрывалось также при тапе вне сообщения, дефект `TATYANA-51` |
| `in3`: действия на разных экранах | При нажатии на каждую активную кнопку появляется сообщение об отсутствии сети | `FAILED`; сообщение появлялось не для всех проверенных кнопок, дефект `TATYANA-51` |

## Пример дефекта: сообщение без сети показывается и закрывается неверно

**Предусловие:** создан курьер; приложение открыто под его учётной записью.

1. Включить авиарежим на устройстве.
2. По очереди нажать «Принять», «Все», «Мои», фильтр метро и карточку заказа.
3. После появления сообщения об отсутствии сети тапнуть вне его области.

**Ожидание по тест-кейсам:** сообщение появляется при нажатии на каждую проверяемую активную кнопку и остаётся открытым до нажатия «Ок».

**Фактический результат в дипломных материалах:** сообщение появлялось не на всех проверяемых кнопках и закрывалось тапом вне его области. Оба отклонения отражены в тест-кейсах `in2` и `in3` и зарегистрированы под номером `TATYANA-51`.

**Что дала проверка:** сочетание авиарежима, разных экранов и способов закрытия окна позволило заметить два нарушения одного пользовательского сценария. Один успешный показ сообщения при отсутствии сети не покрывал остальные действия в приложении.

## Дополнительные проверки

В группе тест-кейсов для push-уведомлений проверяла время появления, текст, доставку при закрытом приложении и переход по уведомлению. В дипломном чек-листе доставка при закрытом приложении (`m5`) и переход на вкладку «Мои» (`m6`) отмечены `PASSED`; проверки времени появления (`m1`–`m3`) и текста (`m4`) отмечены `FAILED`.

**Источник:** дипломные тест-кейсы «Задание 3» по мобильному приложению Яндекс Самокат. Ссылки на старые задачи YouTrack сейчас недоступны, поэтому номера дефектов приведены по исходной таблице. Точные тексты фактических сообщений и изображения экранов в этом кейсе не воспроизводятся по памяти.
